# Solutions for Women

My older sister was volunteering with [Solutions for Women](https://solutionsforwomen.net), a San Francisco nonprofit that connects women to resources, emotional wellness and education. They're such a sweet organization, but their website was definitely a bit dated, so I rebuilt it.

It's a static site built with Astro, so there's no database, no plugins and no monthly platform fee, and it loads fast on phones. I also set it up so the old Wix links still redirect, the forms work, and donations go through PayPal.

```sh
npm install
npm run dev       # http://localhost:4321
npm run build
```
